A Flood Prediction Method Integrating MSSU and VGDAG-STNN Under Limited Data

2025–2026
Smart City PyTorch PyTorch Geometric GCN LSTM CFD
Motivation: Flood prediction in small basins is hindered by sparse data and evolving upstream-downstream dynamics. This work builds upon my earlier MSSU concept (2023) and integrates it with a novel algorithm, while also incorporating the 2025 prototype validation of the MSSU hardware.
Approach: Paired a low‑cost Mobile Spherical Sensing Unit (MSSU) with a VGDAG‑STNN model — a Velocity‑Guided Dynamic Acyclic Graph that adapts its topology to real‑time flow, plus an attention‑enhanced Seq2Seq network. The MSSU hardware was prototyped and validated in three field environments (urban, suburban, mountainous).
Key result: With only 33 simulated samples, the model forecasts 60‑minute flood conditions with R² = 0.999, outperforming LSTM and GCN‑LSTM baselines. MSSU prototype achieved 100% packet rate in urban environments.
Poster · ICBS 2026
Accepted by Young Scholars Academic (YSA) Vol. 11 (Oct 2026)
Core Innovation: VGDAG Physics‑Guided Edge Construction
Node Resultant Velocity
$$ v_i = \sqrt{Ux_i^2 + Uy_i^2 + Uz_i^2} $$
Instantaneous velocity magnitude at node i.
Dynamic Neighborhood Radius
$$ r_i = \text{clip}\left(r_0 + \alpha \cdot v_i, \; r_{\min}, \; r_{\max}\right) $$
Faster nodes search farther for neighbors.
Directional Screening
$$ \cos\theta = \frac{\mathbf{U} \cdot \mathbf{d}}{\|\mathbf{U}\| \|\mathbf{d}\|}, \quad \text{edge retained if } \cos\theta > \tau \;(\tau = 0.5) $$
Only downstream‑aligned edges ($\theta \approx$ 60°) are kept.
Dynamic Edge Weight
$$ w_{ij} = e_{ij} \cdot \exp(-\beta \cdot d_{ij}) \cdot \text{ReLU}(\cos\theta_{ij}) $$
Sparse edge attention × distance decay × directional consistency.
GCN and LSTM follow standard formulations (Kipf & Welling, 2017; Hochreiter & Schmidhuber, 1997). The above equations represent the core physics‑guided edge construction that distinguishes VGDAG from static graph methods.

Cartesian Coordinate Rapid‑Draw Ruler

2024
Engineering Education Tool Geometry
Motivation: Drawing Cartesian coordinates with tick marks using traditional tools is tedious and error‑prone.
Approach: Designed a multifunctional ruler integrating a protractor, square‑root scale, and a patented notch design that outputs uniform "V"‑shaped tick marks in a single stroke.
Key result: Reduces drawing time from 11 strokes to 1 stroke for a 10‑unit axis; improves accuracy and usability for students and teachers.

Solar-Powered Spherical Sensor for Flood Monitoring

2023
Smart City Hardware Design GPS IoT
Motivation: Urban manhole covers (2021) provided a fixed infrastructure for flood sensing, but could not cover remote, ungauged basins. A deployable solution was needed.
Approach: Proposed a floating spherical sensor with GPS, solar‑powered battery, and satellite data transmission. The design evolved from the float‑beacon concept embedded in my 2021 smart manhole cover — but untethered from urban infrastructure, it can be deployed via UAV in areas without manhole networks.
Key result: The concept was documented in a research paper describing the hardware architecture and data transmission framework for a floating sensor network. This work directly informed the MSSU hardware prototype later validated in the VGDAG project (2025–2026).
Note: This is a concept paper (2023). The prototype validation and algorithm integration are part of the VGDAG project (2025–2026).

Electric Vacuum Blackboard Eraser

2022
Hardware DIY Classroom Tool
Motivation: Traditional blackboard erasers scatter chalk dust, affecting teachers' respiratory health.
Approach: Built a battery‑powered eraser with a negative‑pressure fan (modified electric fan) that draws dust into a detachable, washable container. The eraser features dual replaceable sponge strips with central suction channels for left‑ and right‑handed use.
Key result: The device effectively captures chalk dust; future upgrades include inductive charging, full‑washability, and front‑mounted switch for daily teacher use.

Smart Manhole Cover IoT Network for Urban Flood Management

2021
Smart City IoT Big Data Urban Planning
Motivation: Urban flooding causes severe damage, but real‑time road‑level water data is unavailable.
Approach: Proposed a city‑wide smart manhole cover network with embedded sensors (flow, pressure, float‑beacon). Designed a dual‑layer cover with debris filtration, and a pressure‑fuse system that triggers alerts during extreme flood events.

Anti‑Epidemic Board Game for Primary Students

2020
Game Design Health Education
Motivation: Children needed an engaging way to learn COVID‑19 hygiene protocols and remember key events.
Approach: Designed a 81‑grid board game (inspired by "Journey to the West" — 81 trials) from home to school. Each grid features real pandemic events (mask‑wearing, handwashing, Fangcang hospitals, nucleic acid tests) with reward/penalty mechanics.
Key result: Prototype tested with family; received positive feedback for both learning reinforcement and memorial value.
