## Featured Projects

- **VGDAG-STNN (2025–2026):** A flood prediction method integrating MSSU and VGDAG-STNN under limited data, combining a Mobile Spherical Sensing Unit with a physics-guided dynamic graph neural network. ([Code](https://github.com/Qingran-Yu/Flood-Prediction))

- **Ruler (2024):** Cartesian Coordinate Rapid‑Draw Ruler — a multifunctional ruler integrating a protractor, square-root scale, and a patented notch design that outputs uniform tick marks in a single stroke.

- **MSSU (2023):** Solar-Powered Spherical Sensor for Flood Monitoring — a deployable floating sensor concept designed for remote, ungauged basins, evolving from an earlier manhole-based float-beacon design.

- **Eraser (2022):** Electric Vacuum Blackboard Eraser — a battery-powered device with a negative-pressure fan that captures chalk dust, designed for classroom use.

- **Manhole (2021):** Smart Manhole Cover IoT Network for Urban Flood Management — a city-wide smart manhole cover network with embedded sensors (flow, pressure, float-beacon) and a pressure-fuse system for extreme flood alerts.

- **Chess (2020):** Anti‑Epidemic Board Game for Primary Students — an 81-grid board game designed to teach COVID‑19 hygiene protocols through reward/penalty mechanics. (Game Design + Health Education)
